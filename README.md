## 🌐 Executive Overview

Welcome to the official repository for the **Armana Group Premium Portal**. Founded in 1995, Armana Group has evolved into a global denim conglomerate and export powerhouse, supplying world-renowned apparel brands including **Levi's, GAP, H&M, and Benetton**. 

This repository houses the source code for the official corporate multi-page web portal, engineered with high-performance front-end technologies to deliver a sophisticated user experience, responsive asset management, and seamless navigation across global markets.

> *"Weaving sustainable excellence into every thread, driving the future of global apparel manufacturing with uncompromising precision."*
> — **Armana Group Leadership**

---

## 🚀 Key Modules & Architecture

The portal is architected as a high-performance multi-page application (MPA), meticulously organized into distinct interactive sections:

*   **Home Portal (`index.html`):** The primary engagement hub featuring live operational metrics, high-impact brand statements, and quick-access navigation layers.
*   **Why Armana (`why-armana.html`):** An exposition of our foundational pillars, compliance standards, and state-of-the-art manufacturing capabilities.
*   **About Us (`about.html`):** Corporate history featuring an interactive chronological timeline and detailed insights into our specialized industrial subsidiaries.
*   **Products Catalog (`catalog.html`):** An interactive, filterable showcase featuring **50+ curated apparel and denim items** complete with specification sheets.

## 🛠️ Tech Stack & Design Architecture

Built with a performance-first philosophy, relying on native web technologies to guarantee instantaneous load times and robust cross-browser compatibility:

## 💻 Local Development & Installation

To run or inspect the portal locally on your workstation, follow these simple steps:

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/armana-group/portal-website.git
   ```

2. **Navigate to Project Directory:**
   ```bash
   cd armana-group-portal
   ```

3. **Run a Local Development Server:**
   You can use any local static server (e.g., Live Server extension in VS Code, Python HTTP server, or Node `http-server`):
   ```bash
   # Using Python 3
   python3 -m http.server 8000
   ```

4. **Access in Browser:**
   Open your web browser and navigate to `http://localhost:8000`.
